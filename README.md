# Professional Personal Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, and Tailwind CSS.

## 🚀 Live Deployment to GitHub Pages

This repository is pre-configured with a GitHub Actions workflow in `.github/workflows/deploy.yml` for automated deployment to GitHub Pages.

### How to Deploy via GitHub Website (No terminal needed):

1. **Create a Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Name it `portfolio` and set visibility to **Public**.
   - Click **Create repository**.

2. **Upload Files**:
   - Click **Upload files** (or drag and drop).
   - Drag all project files into GitHub (include `.github`, `src`, `index.html`, `package.json`, etc.).
   - Click **Commit changes**.

3. **Enable GitHub Pages**:
   - Go to repository **Settings** → **Pages**.
   - Under **Build and deployment** > **Source**, select **GitHub Actions**.

4. **Done!**
   - Click the **Actions** tab to watch the build.
   - Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
